# ✈️ Voyage AI — Agentic AI Travel Planner

**An intelligent, multi-agent travel planning application that generates personalized itineraries using specialized AI agents, external APIs, and Google Gemini.**

Voyage AI helps users plan trips by combining destination discovery, weather information, flight and accommodation suggestions, budget estimation, and AI-generated day-wise itineraries in a modern, interactive Gradio dashboard.

---

## 🌍 Overview

Planning a trip often involves searching across multiple platforms for attractions, weather forecasts, transportation, accommodation, and estimated expenses.

**Voyage AI brings these steps together in one application.** Users enter their starting city, destination, and trip duration. The system coordinates specialized agents to collect available information, estimate expenses, and generate a personalized itinerary.

The application features a premium dashboard with a responsive layout, trip summary cards, agent status indicators, dedicated result tabs, and an interactive OpenStreetMap view.

## ✨ Key Features

- 🤖 **Multi-Agent Architecture** — Separate agents handle transportation, accommodation, activities, weather, budgeting, and itinerary recommendations.
- 📍 **Destination Geocoding** — Uses Geoapify to resolve destination coordinates.
- 🏛️ **Tourist Attraction Discovery** — Retrieves places of interest using OpenTripMap.
- 🌦️ **Weather Information** — Uses Open-Meteo to retrieve weather data for the destination.
- ✈️ **Flight Suggestions** — Provides simulated flight options for trip planning.
- 🏨 **Accommodation Suggestions** — Displays simulated hotel recommendations and indicative prices.
- 💰 **Budget Estimation** — Calculates estimated trip expenses.
- 🧠 **AI-Generated Itinerary** — Uses Google Gemini to generate personalized travel recommendations.
- 🗺️ **Interactive Map** — Displays a destination map using OpenStreetMap.
- 📊 **Trip Overview Dashboard** — Summarizes the route, duration, weather, attractions, and estimated budget.
- 🎨 **Modern UI** — Built with Gradio, featuring a premium dashboard, responsive cards, and organized result tabs.

## 🖥️ Application Interface

The Voyage AI dashboard is organized into the following sections:

| Section | Information displayed |
|---|---|
| Trip Planner | Starting city, destination, and number of days |
| Trip Overview | Route, duration, temperature, attraction count, and estimated budget |
| Flights | Simulated airline options, duration, stops, and indicative fares |
| Hotels | Simulated accommodation options and estimated nightly prices |
| Attractions | Tourist attractions returned by the activity workflow |
| Weather | Temperature, humidity, wind speed, and timezone when available |
| Budget | Estimated flight, accommodation, and other expenses |
| AI Itinerary | Personalized recommendations generated by the recommendation agent |
| Map | OpenStreetMap view of the attraction area when coordinates are available |
| Agent Status | Overview of the travel-planning workflow |

## 🔌 API Integrations

### 1. Google Gemini API

Generates personalized itinerary recommendations based on the information supplied by the workflow.

**Used for:**
- AI-generated travel recommendations
- Day-wise itinerary generation
- Personalized suggestions based on available trip information

### 2. Geoapify API

Converts destination names into geographical coordinates.

```text
Destination name
       ↓
Geoapify Geocoding API
       ↓
Latitude and Longitude
```

The coordinates can then be used by location-based services.

### 3. OpenTripMap API

Retrieves tourist attractions and points of interest around the destination.

```text
Destination
     ↓
Geographical coordinates
     ↓
OpenTripMap API
     ↓
Tourist attractions
```

### 4. Open-Meteo API

Provides weather information using geographical coordinates.

Depending on the response returned by the weather agent, the dashboard can display temperature, humidity, wind speed, and timezone.

### 5. OpenStreetMap

Displays a map of the geographical area covered by the returned attraction coordinates.

The current map implementation uses an embedded OpenStreetMap view. It does not yet display custom markers for every attraction.

## 🔄 Application Workflow

1. The user enters the starting city, destination, and number of days.
2. The Gradio interface validates the trip details.
3. `TravelWorkflow` coordinates the existing travel agents.
4. The destination is resolved into geographical coordinates using Geoapify.
5. The activity agent retrieves tourist attractions through OpenTripMap.
6. The weather agent retrieves available weather information from Open-Meteo.
7. The transport agent returns simulated flight options.
8. The accommodation agent returns simulated hotel suggestions.
9. The budget agent calculates an estimated trip cost.
10. The recommendation agent uses Google Gemini to generate a personalized itinerary.
11. The dashboard displays the available results through summary cards, tabs, and a map.

## ⚙️ Installation and Setup

### Prerequisites

- Python 3.10 or later, compatible with your installed dependencies
- pip
- API keys for the services you intend to use
- Internet connectivity for external API calls

### Step 1: Clone the repository

```bash
git clone https://github.com/SujithVarma-ai/agentic-ai-travel-planner.git
cd agentic-ai-travel-planner
```

If your repository URL or repository name differs, replace the URL with your actual GitHub repository.

### Step 2: Create a virtual environment

**Windows PowerShell**

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

**macOS / Linux**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### Step 3: Install dependencies

If `requirements.txt` already exists:

```bash
pip install -r requirements.txt
```

Otherwise, install the dependencies used by your implementation and create a requirements file:

```bash
pip install gradio python-dotenv requests
```

Install the Google Gemini SDK or other packages required by your existing agent implementations as well. The exact dependency list depends on your source files.

### Step 4: Configure API keys

Create a `.env` file in the project root.

```env
GEMINI_API_KEY=your_gemini_api_key
GEOAPIFY_API_KEY=your_geoapify_api_key
OPENTRIPMAP_API_KEY=your_opentripmap_api_key
```

Replace the placeholder values with your own API keys.

Open-Meteo generally provides access to its forecast API without an API key for standard use, subject to its current terms and usage limits.

**Security:** Never commit your `.env` file or publish API keys in your repository.

Add the following entries to `.gitignore`:

```gitignore
.env
.venv/
__pycache__/
*.py[cod]
```

### Step 5: Run the application

From the project root:

```bash
python ui/gradio_app.py
```

Open the local URL displayed in the terminal, usually:

**http://127.0.0.1:7860**

## 📊 Data Accuracy and Current Limitations

The application combines live external information with simulated planning data.

| Component | Current behavior |
|---|---|
| Flight options | Simulated; not live airline inventory |
| Hotel suggestions | Simulated; not verified availability |
| Tourist attractions | Retrieved from OpenTripMap when available |
| Weather | Retrieved from Open-Meteo when available |
| Geocoding | Geoapify, when configured and available |
| AI itinerary | Generated using Gemini, when configured and available |
| Trip budget | Estimated from the available agent outputs |
| Map | OpenStreetMap embedded view based on returned coordinates |
| Agent status | Workflow-level completion indicator, not independent agent health monitoring |

Flight and hotel prices should be treated as indicative examples, not bookable offers. The estimated budget is not a guaranteed final trip cost.

External API failures, rate limits, missing coordinates, or invalid credentials may result in incomplete results.
